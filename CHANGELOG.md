# Changelog

All notable changes to Erthoric will be documented in this file.

## [1.0.0] - 2024-01-01

### Added
- Initial release of Erthoric
- Real-time earthquake data from USGS
- Continental earthquake filtering
- Largest earthquakes display
- City alert system
- Interactive console menu
- Multi-platform support

### Features
- 🌍 Real-time earthquake monitoring
- 🗺️ Continent-based filtering
- 💥 Largest earthquakes view
- 🔔 Custom city alerts
- 📊 Active alerts management
- 🔄 Auto-refresh data

### Technical
- Built with Python 3.6+
- Uses USGS public API
- Cross-platform compatibility
- No external dependencies besides requests
